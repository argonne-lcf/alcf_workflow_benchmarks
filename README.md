# ALCF Workflows Benchmarks

This repository contains benchmarks for workflows of interest to ALCF and its users, anything from communication micro-benchmarks to full workflow patterns.

Below is a summary of the benchmarks provided.

| Benchmark | Description | Tools | Systems Supported |
|-----------|-------------|-------|-------------------|
| [workflow_stream](./workflow_stream) | Benckmark data streaming or staging performance for a simple producer-consumer workflow pattern. | MPI, ADIOS2, SmartSim, DragonHPC | Aurora |
